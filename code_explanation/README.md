# 🎓 FinAgent Code Explanation & Interview Masterclass (React / Vite App)

An interactive, visual learning application that breaks down every single file, class, method, RAG pipeline, multi-agent node, deterministic tool, and Morgan Stanley interview question for the **FinAgent** system.

---

## 🚀 How to Run Locally

1. Open your terminal and navigate to this folder:
   ```bash
   cd code_explanation
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at:
   ```
   http://localhost:5173
   ```

---

## 🌟 Key Features

* **File-by-File Line Breakdown:** Explains what every file does, why it exists, and how it fits into the Wall Street architecture.
* **Multi-Agent Architecture View:** Visual interactive state graph diagrams for LangGraph.
* **Interview Masterclass Tab:** High-frequency Morgan Stanley technical interview questions, grading rubrics, and model answers.
* **Live Search & Filter:** Instant search across all codebase modules, docstrings, and financial formulas.
