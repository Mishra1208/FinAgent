# FinAgent

FinAgent is an SEC 10-K filing analysis system that uses retrieval-augmented generation (RAG) and deterministic calculation tools to answer financial and risk questions about public company filings (currently covering AAPL, MS, and MSFT).

Instead of relying on an LLM to perform arithmetic or recall numbers from memory, FinAgent pairs LangGraph multi-agent routing with deterministic Python functions for financial ratios, and uses hybrid retrieval (dense vector embeddings + BM25 keyword search) to ground answers in actual filing excerpts.

🔗 **Live Demo:** [finagentai.streamlit.app](https://finagentai.streamlit.app/)

## Architecture

```
                      [ User Query ]
                            │
                            ▼
                  [ Input Guardrails ]
            (Prompt injection & scope checks)
                            │
                            ▼
                 [ Supervisor Agent ]
           (Query routing & state management)
                            │
             ┌──────────────┴──────────────┐
             ▼                             ▼
   [ Hybrid RAG Engine ]          [ Quant Analyst ]
   • ChromaDB (Dense)             • Raw figure extraction
   • BM25 (Sparse keyword)        • Deterministic math tools
   • Reciprocal Rank Fusion         (YoY, margins, CET1)
             │                             │
             └──────────────┬──────────────┘
                            ▼
                  [ Risk Auditor ]
             (Item 1A risk extraction)
                            │
                            ▼
              [ Grounding Verifier ]
             (Factual citation check)
                            │
                            ▼
                  [ Final Response ]
               (Streamlit UI / FastAPI)
```

## What It Does

- **SEC Filing Retrieval:** Chunks and indexes 10-K reports (Items 1, 1A, 7, and 8) using ChromaDB dense embeddings and BM25 keyword search, merged via Reciprocal Rank Fusion (RRF).
- **Deterministic Financial Math:** Ratios, margins, and growth figures (e.g., YoY sales growth, gross margin %, efficiency ratios, CET1) are computed with pure Python arithmetic rather than generated by the LLM.
- **Multi-Agent Orchestration:** A LangGraph state graph coordinates specialized agents:
  - **Supervisor:** Determines query intent and coordinates agent execution.
  - **Quant Analyst:** Extracts numerical inputs and calls deterministic financial calculation tools.
  - **Risk Auditor:** Extracts and categorizes Item 1A risk disclosures (e.g., supply chain concentration, geopolitical risks).
  - **Grounding Verifier:** Checks that cited figures and claims match retrieved filing chunks before returning the response.
- **Guardrails:** Validates user inputs against prompt injection / off-topic queries and applies Pydantic schema validation to structured outputs.

## Evaluation Results

Evaluation is automated via `tests/test_evaluation_benchmark.py` using Ragas metrics across four specific 2024 10-K audit scenarios:

| Metric | Score | Target | Description |
| :--- | :---: | :---: | :--- |
| **Faithfulness** | **1.00** | ≥ 0.95 | Generated claims are directly grounded in the retrieved filing excerpts (no hallucinations observed). |
| **Answer Relevance** | **0.98** | ≥ 0.90 | Answers directly address the user's prompt. |
| **Context Precision** | **0.96** | ≥ 0.90 | Retrieved chunks contain the exact financial items and tables requested. |
| **Context Recall** | **0.95** | ≥ 0.90 | The system retrieved all necessary excerpts to answer the test queries. |

> **Plainly stated:** Tested on a 4-question test set auditing 2024 10-K filings for Apple (net sales & gross margins; TSMC supply chain risk) and Morgan Stanley (net income & efficiency ratio; CET1 capital adequacy), the system achieved **faithfulness of 1.00**—meaning every numerical figure and factual claim in the test set was verified against retrieved filing text.

## How to Run It

### Prerequisites
- Python 3.10+
- An API key (OpenAI or Google Gemini)

### 1. Clone & Set Up Virtual Environment

```bash
git clone https://github.com/Mishra1208/FinAgent.git
cd FinAgent

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Configure Environment Variables

```bash
cp .env.example .env
# Edit .env and insert your API key (OPENAI_API_KEY or GOOGLE_API_KEY)
```

### 3. Run the App

- **Streamlit Web UI:**
  ```bash
  streamlit run src/ui/app.py
  ```
  Access at `http://localhost:8501`.

- **FastAPI Backend (Optional):**
  ```bash
  uvicorn src.api.main:app --host 127.0.0.1 --port 8000 --reload
  ```
  Interactive Swagger API docs at `http://127.0.0.1:8000/docs`.

- **Run Evaluation Benchmarks & Unit Tests:**
  ```bash
  python tests/test_evaluation_benchmark.py
  python tests/test_multi_agent.py
  ```
